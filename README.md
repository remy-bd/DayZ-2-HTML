# 🗡️ Projet TP Web : Jeu d'Aventure à Choix Multiples

## 📁 Structure du Projet

```text
ProjetHTML/
├── index.html              # Page d'accueil (point de départ du jeu)
├── style.css               # Feuilles de styles CSS globales
├── pages/                  # Toutes les scènes du jeu (min. 10 pages)
│   ├── scene01.html
│   ├── scene02.html
│   └── ...
├── assets/
│   ├── backgrounds/        # Images d'ambiance et fonds des scènes
│   ├── icons/              # Icônes pour les boutons d'action
│   └── sounds/             # Musiques et effets sonores (optionnel)
├── docs/
│   └── arbre-navigation.pdf # Schéma / Arbre de navigation obligatoire
└── README.md               # Présentation du projet
```

---

## 🎯 Rappel des consignes & critères

- **Minimum 10 pages interconnectées** (histoire ramifiée avec fins multiples).
- **Structure par page** : Titre du lieu, image de fond / ambiance, paragraphe narratif, choix d'actions personnalisés (boutons avec icônes).
- **Arbre de navigation** : Document PDF traçant les chemins possibles.
- **Bonus possibles** : Ambiance sonore, animations CSS, inventaire / PV en JavaScript.
